# Data Directory

Due to GitHub file size limits, datasets in this directory are gitignored:
- `data/raw/2019-Oct.csv`: 5.67 GB raw clickstream dataset (42.45M events). Download from Kaggle:
  `kaggle datasets download -d mkechinov/ecommerce-behavior-data-from-multi-category-store -f 2019-Oct.csv.gz -p data/raw/`
- `data/bronze/events_oct`: Partitioned Parquet bronze lakehouse (generated by `notebooks/01_setup_and_data_quality.py`).
- `data/silver/events_oct`: Cleaned Parquet silver lakehouse (generated by `notebooks/02_elt_and_star_schema.py`).
- `data/gold/`: Star Schema DuckDB warehouse and feature marts (generated by Phase 2 & 4).

All curated BI tables are available in `dashboard/` and all evaluation reports are in `reports/`.
